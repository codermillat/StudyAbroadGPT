# v4 50-prompt evaluation set

This directory contains the 50-prompt held-out evaluation set used in
arXiv:2504.15610v4 §4.3, plus the deterministic base and LoRA model
outputs from the v4 evaluation. It is the input to the v5 §3 stratified
causal test (the pre-registered analysis plan at
`docs/analysis-plans/2026-09-02-stratified-causal-test.md`).

## Files

| File | Description |
|------|-------------|
| `evaluation_prompts.csv` | The 50 held-out prompts (256-token re-run). Columns: `prompt_id`, `prompt`. |
| `base_model_outputs.csv` | Deterministic base-model outputs on the 50 prompts. |
| `lora_model_outputs.csv` | Deterministic LoRA-model outputs on the same 50 prompts. |
| `eval-prompts-512.csv` | The 50 held-out prompts (512-token re-run; same prompt set, different token cap). |
| `base-model-outputs-512.csv` | 512-token base-model outputs. |
| `lora-model-outputs-512.csv` | 512-token LoRA-model outputs. |

## Generation settings (v4 §3.5.1)

Both runs use:

- **Base model**: `mistralai/Mistral-7B-Instruct-v0.3` (4-bit NF4)
- **LoRA model**: `millat/StudyAbroadGPT-7B-LoRa-Kaggle` (merged, 4-bit NF4)
- **Sampling**: `do_sample=False`, `temperature=0.0`, `top_p=1.0`
- **Token cap**: 256 (default) or 512 (re-run; recommended for factuality analysis because 96% of 256-token responses truncate)
- **Chat template**: Mistral-Instruct native (`[INST] ... [/INST]`)
- **Hardware target**: a single 16 GB GPU (Kaggle T4 or Colab T4)

The 50 prompts are a deterministic topic-stratified sub-sample of the
402-prompt held-out test split, drawn with `random.seed(42)`.

## Why two token caps

At 256 tokens, 96% of both base and LoRA responses hit the cap. v4
re-ran the same comparison at 512 tokens, where the truncation rate
drops to 24% (base) / 20% (LoRA). The 512-token re-run is the
recommended input for any factuality analysis because the truncated
256-token responses can artificially match the reference style without
providing enough room to make a verifiable claim. v4 §4.3.3 reports
the 512-token numbers; the 256-token run is preserved for transparency.

## Known sensitive content

The prompts are study-abroad questions (admissions, visas, scholarships,
cost of living, etc.) generated by Gemini 1.0 Pro as part of the
synthetic dataset. **No real student data is in this directory.**
The responses are model outputs, not user-provided text.

## Provenance

The prompts are derived from the held-out test split of
`millat/StudyAbroadGPT-Dataset` (the 402-prompt test set). The base
and LoRA outputs were generated as part of the v4 evaluation pipeline
documented in `paper/main.tex` §3.5.

The HF card for the dataset (commit `3f91dd0`, 2026-09-02) and the
model card (commit `687758d`, 2026-09-02) document the v4 facts
referenced in this directory.

## How to use for the v5 §3 stratified test

The `evaluation_prompts.csv` file is the input to
`scripts/eval/stratify_prompts.py`. The full v5 pipeline is:

1. **Audit extension** — source-verify ~85 new training answers
   (`python3 scripts/eval/audit_training_neighbors.py generate --mode mixed`).
2. **Stratify** — assign each of the 50 prompts to C, W, or M based on
   its training neighbors (`python3 scripts/eval/stratify_prompts.py`).
3. **Generate** — produce base + LoRA outputs on the stratified subset
   (`python3 scripts/eval/generate_stratified.py`).
4. **Audit** — source-verify the (prompt × model) pairs.
5. **Analyze** — run McNemar's test per stratum, with bootstrap CIs
   (`python3 scripts/eval/analyze_stratified.py`).
6. **Update v5 §4.5** with the resulting table and forest plot.
